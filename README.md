# 寻归荒野

互动叙事《寻归荒野》的静态站点。整个游戏就在 `index.html` 一个文件里，`assets/` 下是音乐、彩蛋视频与纸墨素材。

- 在线地址：https://wanghuning1949-commits.github.io/xungui/
- 部署方式：GitHub Pages，`main` 分支根目录
- 更新方式：把新版本的包解压、覆盖这里的文件，提交并推送即可，网址不变

说明文档见 `README.txt`（怎么打开、怎么部署、这一版核对过什么）。`netlify/` 目录是给 Netlify 部署用的函数，GitHub Pages 不运行它们；在这种纯静态托管下，公告会显示内置的默认内容，音乐搜索走公开接口回退，不影响游玩。
